# einf vs einops vs einx Dynamic-Shape Benchmark

> Historical descriptive artifact. This report predates the dynamic raw
> observation receipt and does not retain enough identity to reconstruct paired
> effects or uncertainty intervals. Numeric tables are preserved as captured;
> marginal IQR overlap or separation is not a significance test.

## Configuration

- Python: `3.11.10`
- NumPy: `2.4.4`
- torch: `2.11.0`
- einops: `0.8.2`
- einx: `0.4.3`
- einf: workspace source (`src/einf`)
- backend: `torch`
- sizes(base): `b=16, n=192, d=96, h=32, w=24, r=16, j=128`
- each dimension is sampled per batch in `[0.6x, 1.4x]` of base size
- seed: `20260215`
- round order seed: `20260215`
- total batches per case: `32`
- warmup batches: `4`
- repeats per round: `5`
- rounds: `3`
- measured batches per repeat: `28`
- call observations per library/case: `420`
- paired round/batch workload units per library/case: `84`
- table units: `ms`

## Methodology

- Each case uses deterministic dynamic inputs generated by seeded `RandomState`.
- In each round, every measured batch is executed in paired cross-library order on the same logical batch stream.
- Each post-warmup batch call contributes one latency observation.
- Each library receives independently materialized backend batches to avoid cross-library input locality artifacts.
- Within each round, per-batch library order rotates from the reported base order to spread position bias.
- Round summaries expose residual order-sensitive variation; aggregate stats pool all call observations across rounds.
- Repeats measure the same round/batch workload unit and are not independent samples.
- This archived Markdown does not retain the observation identities required for paired effect or uncertainty reconstruction.
- Reported stats: `count`, `p25`, `median`, `p75`, `p95`, `mean`, `min`, `max`.
